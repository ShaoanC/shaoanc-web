# Friendly Captcha 登录与注册保护

## 实施任务

| 任务 | 状态 | 交付 |
|---|---|---|
| 后端核验、故障降级与限流 | in_progress | 登录、注册接口与公开配置 |
| 前端验证组件与认证表单 | pending | Global、Focus，错误与过期重试 |
| 构建、烟测与浏览器检查 | pending | 聚焦认证变化的验证 |
| 部署说明与完成记录 | pending | 生产配置、真实网络验收说明 |

## 场景

每次登录（包括管理员）和邀请码注册需要人机验证。登录后修改密码、管理员重置用户密码及错题操作沿用现有认证流程。未来增加匿名找回密码时，在发送重置邮件或短信的入口接入验证。
