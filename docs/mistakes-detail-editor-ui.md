# 详情阅读页与编辑工作台

详情页采用单栏阅读，编辑页在电脑端展开全部字段、手机端切换标签。沿用纸白与墨绿，编辑状态使用浅金提示。

## 任务清单

- completed：详情单栏阅读，保留分类、星级、复习记录及回收站能力。
- completed：编辑工作台与手机题干／解答／笔记／归类标签，保留所有输入与预览状态。
- completed：右下软盘展开保存菜单与配套骨架、动效和可访问状态。
- completed：构建及集中浏览器检查，记录结果。

保存草稿与保存归档沿用原接口；已归档题目的主操作显示“保存修改”。完成实现与验证后，按项目规则创建 Git 自动回退点。

## 验证

`npm run build` 通过，包含 TypeScript 类型检查。使用 `data/` 下的独立 SQLite 数据库，经 Express 静态服务检查 1280px 电脑与 390px 手机界面，页面无横向溢出。

电脑端四个内容字段全部展开；手机端切换题干、解答、笔记和归类后，输入内容与各字段的编辑／预览状态保留。软盘按钮向上展开保存选项，支持 Escape 收起。由归类标签保存已归档题目后，详情正确显示全部字段的修改；空题归档会切回题干标签并聚焦输入，也可以保存为草稿。星级及复习记录正常显示。

收尾时压缩详情星级区域，并重新构建确认最终样式。后端接口与数据结构未改动。
