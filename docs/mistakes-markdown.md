列表摘要按语法树平铺，保留文字格式与完整数学节点，不产生内部链接、图片或任务复选框。列表和复习选题显示两行，卡片显示三行；超出部分仅视觉裁切，完整公式在详情中查看。全文的宽公式、表格与代码块在内容区内滚动。
