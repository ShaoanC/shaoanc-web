# 手机端错题筛选

手机宽度不超过 640px 时，我的错题列表仅常驻搜索框和筛选入口。学科、知识点、掌握程度及星级在 Base UI Drawer 底部弹层中设置，点击“应用筛选”后统一更新列表。

关闭、遮罩或下滑退出时不应用修改；“重置”只清空暂存条件。入口显示已生效条件数量，不包含关键词。桌面筛选继续即时生效，归档、草稿及回收站共用同一套筛选。
