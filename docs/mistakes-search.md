## 使用规则

- 搜索范围包括题干、答案、解析、笔记、学科和主辅知识点名称。
- 多个词允许部分匹配；命中词更多的题优先，然后按相关度、更新时间和 ID 排序。
- 中文索引补充单字和二字词，英文忽略大小写及全角差异；最后一个英文词支持前缀，至少五个字母的英文词允许一个字符的拼写误差。
- 搜索结果保留来源标签，每道题最多显示两条匹配摘要；没有摘要时不显示摘要容器。列表与卡片使用相同的摘要展示。
- 匹配摘要经 Markdown 解析后去除标题、粗体、列表、链接等格式，保留可读文字和完整的行内、块级公式。题干预览仍沿用现有 Markdown 展示。
- 摘要按实际匹配位置高亮普通文字；命中公式内部时，整条公式加高亮背景。公式通过 KaTeX 渲染，长公式在摘要内横向滚动，渲染失败时显示公式原文。
- 摘要窗口以约 120 字为目标，截断边界落入公式时扩展到公式边界，避免拆开 LaTeX。公式片段使用可选的 `type: 'math'` 和 `display` 字段；普通片段仍使用 `text` 和 `matched`，缺少 `type` 时按普通文字处理。
- 搜索时显示“搜索结果 N 道”，仅使用筛选时显示“筛选结果 N 道”。搜索框提示为“搜索错题内容、学科或知识点”，无搜索结果时提示“没有找到相关错题”，并引导调整关键词或筛选条件。
- 页面不再提供“数据类型”筛选；后端 `dataType=test|formal` 参数仍兼容已有调用，保留测试错题标签和测试数据管理工具。
- 空白搜索沿用最近更新时间排序；只含标点且没有可检索词项时返回空结果。搜索不包含拼音、语义或数学公式等价检索。

## 部署与索引

使用 Node.js 24 和单个 Node 进程，沿用 `npm ci --cache ./data/.npm-cache`、`npm run build` 与 `npm start`。账号首次搜索时从 SQLite 建立索引，LRU 最多保留最近 10 个账号。服务重启后按需重建，不写额外索引文件。

普通错题增删改同步已缓存索引；批量测试题操作清除对应账号缓存；知识点名称、层级或删除操作清除全部缓存。账号权限和各筛选条件仍由 SQLite 提供，复习状态不缓存到文本索引。
