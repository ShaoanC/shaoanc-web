## 兼容与运行行为

`GET /mistakes` 不带 `page` 时继续返回完整数组，供复习、导出与既有调用使用。带 `page` 时返回 `{ items, total, page, pageSize }`，`summary=true` 省略答案、解析和笔记正文。搜索继续按相关性排序后分页。

未保存文字只存于当前浏览器，并按账号隔离；恢复编辑不会自动覆盖其他页面的新内容。未上传图片仍需重新选择，离页时会提醒。整页上传离页即取消，已被服务器接收的页面继续在后台分题，返回时可查看。

发布时照常保留数据库、图片目录和 `.env.ai`。首次启动自动新增创建去重表并清理历史孤儿题框关联。

## 2026-11-13 草稿跨页全选

草稿箱点击“选择题目”后，可点击“全选全部草稿”；存在搜索或筛选时，按钮改为“全选筛选结果”。列表首次加载 32 道摘要，滑到底部自动追加 32 道，每页最多 128 道，再通过“下一页”继续。全选仅请求编号，不加载其他页的正文、图片或公式。翻页保留草稿选择，可逐题取消或使用“全选已加载”切换当前已显示的题目；更换筛选条件、退出选择会清空选择。已归档列表翻页时清空选择。

`GET /mistakes/selection` 复用列表筛选及搜索排序，只返回当前账号未删除草稿的 `{ ids }`，不受列表分页影响。归档按每批最多 100 道调用既有接口，成功题目移出选择，未成功及未处理的题目保留，方便完善后重试。导出所选题目也使用完整跨页编号。
