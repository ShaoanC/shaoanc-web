# 错题快捷删除与回收站

电脑端点击右侧“删除”按钮后，按钮变为“确认删除”；再次点击才会移入回收站。点击其他位置或按 Escape 可取消确认。

移动端首次向左滑动 48px 后露出 88px 宽的红色删除区，首次长滑也只展开入口。松手后再次左滑 48px，或直接点击删除区，执行删除。向右滑动可收起，纵向滚动保持正常。

滑动采用接近 iOS 的阻尼和回弹：首次拖过删除区宽度后逐渐增加阻力，松手回弹到展开位置；第二次左滑时删除区随手指拉伸，整个露出区域都保持红色。短滑不足触发距离时回弹，开启系统“减少动态效果”时取消回弹动画。

## 回收站

“我的错题”中包含“回收站”标签，支持搜索、筛选、列表和卡片视图。删除后保留原题目、草稿或归档状态，以及复习记录，30 天内可恢复。回收站内容不参与复习候选和学习统计。

每题可恢复或彻底删除，工具栏可清空整个账号的回收站，清空范围不受当前搜索和筛选影响。彻底删除与清空会要求确认。

30 天按删除后的 720 小时计算。服务启动及每小时自动清理过期题目；查看回收站和操作题目时也会补清理。到期后题目及复习记录被彻底删除，不能恢复。

管理员测试错题批量删除也会移入回收站。正式错题和其他账号的数据不受影响。

## 接口

以下路径均基于 `/api/mistakes`，沿用登录和账号归属检查：

| 接口 | 行为 |
| --- | --- |
| `DELETE /mistakes/:id` | 移入回收站；重复操作不延长保留期 |
| `GET /mistakes?deleted=true&lifecycle=all` | 查询回收站，支持现有筛选及搜索 |
| `POST /mistakes/:id/restore` | 恢复题目，返回恢复后的错题 |
| `DELETE /mistakes/:id/permanent` | 彻底删除回收站单题 |
| `DELETE /mistakes/trash` | 清空整个账号回收站，返回 `{ count }` |

错题包含 `deletedAt: string | null`，统计包含 `trashCount`。未过期回收站题目的详情及复习历史可读，编辑和新增复习记录须先恢复。
