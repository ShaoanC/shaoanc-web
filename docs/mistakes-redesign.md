# 拾题页面改版

核心任务：记录错题、整理知识点、通过复习掌握薄弱内容。题干与掌握程度优先于装饰。

视觉方案：纸白 #FCFDFC、墨色 #20392E、墨绿 #176448、浅绿 #EAF2EC、铅笔黄 #D3AB36、批注红 #AE443B。Noto Sans SC 用于操作与正文，Noto Serif SC 用于标题。正文 16–18px，题目列表 17px，主标题 38–44px。内容左对齐，统计使用分隔摘要，题目使用整行列表，手机按信息优先级重新排布。

动效统一使用 cubic-bezier(.22, .61, .36, 1)，主要过渡 320ms，淡入淡出 220ms；支持 prefers-reduced-motion。
